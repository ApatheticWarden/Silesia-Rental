# Silesia Rental 🛠️

A mini-pet project built to practice C# backend development, API integration, and software architecture.

## ⚠️ Disclaimer: The "First Pancake"

Let’s be honest: this project is far from perfect. It’s my first real attempt at building a full application from scratch. You will find mistakes in logic, syntax, and architecture. It’s not a production-ready template. The main goal here is purely educational — to make mistakes, learn how things *shouldn't* be done, and improve my C# and .NET skills.

## 🤖 AI-Generated Frontend

I am a backend developer. My focus is on server-side logic, APIs, and databases. Since I didn't want to spend time writing HTML, CSS, or JavaScript, the entire frontend UI of this application was generated using AI. 

The UI exists solely as a basic client to test my API routing, authentication, and database interactions in a browser instead of Postman. The real engineering work and my actual focus are entirely on the backend.

## 💻 Tech Stack

**Backend (Core focus):**
* C# / .NET
* ASP.NET Core MVC & Web API
* Entity Framework Core
* JWT / Cookie-based Authentication

**Frontend (AI-Generated):**
* HTML / CSS / Vanilla JS
* Bootstrap 5.3 (Dark/Light mode)

## ⚙️ Current Features

* **Authentication:** User registration, login, and basic role-based access.
* **User Portal:** Browsing available tools, renting items, returning tools, and viewing billing history.
* **Admin Dashboard (Work in Progress):** The UI is present, but not all admin features (like user management and advanced rental tracking) are fully implemented yet.
* **Client-Server Separation:** The MVC application acts as a client consuming data from a separate REST API backend.
